## Key Implementation Details

### Approval Mode Semantics
- **AUTO_APPROVE**: Policy permits, no human review needed, operation proceeds automatically
- **HUMAN_APPROVAL_REQUIRED**: Policy escalates to human, operation blocked until approved
- **DENY**: Operation always blocked, cannot be approved

### Approval Source Semantics
- **POLICY_AUTOMATIC**: Approval generated by policy engine (OPA)
- **HUMAN**: Approval granted by authenticated human via POST endpoint

### Immutability Guarantee
- ApprovalArtifact is frozen dataclass (immutable after creation)
- Agents cannot create/modify approval artifacts (restricted to trusted governance engine)
- Store prevents duplicate IDs
- Revocation creates new immutable artifact, doesn't mutate existing

### Self-Approval Prevention (Three Layers)
1. **Creation**: Prevents agent from being both requesting_principal and approving_principal
2. **Approval**: Prevents approving_principal == requesting_principal at POST endpoint
3. **Validation**: Checks prevent_self_approval() in validate_approval_for_execution()

### Temporal Validation
- AUTO_APPROVE: LOW risk (24h), MEDIUM/HIGH (6h) TTL
- HUMAN_APPROVAL_REQUIRED: 30 days to review
- Expired approvals fail validation with specific reason
- Revoked approvals fail validation with revocation reason

### Scope Validation
- Approvals scoped to operation (action) and resource
- Fine-grained capability boundaries enforced
- Scope mismatch prevents execution

## User Intent Verification

✅ **"Approval must be automatic whenever the operation satisfies policy. Human-in-the-loop must be an explicit escalation, not the default."**
- AUTO_APPROVE mode is default for policy-permitted operations
- HUMAN_APPROVAL_REQUIRED is explicit escalation by policy rule
- DENY is explicit denial by policy rule

✅ **"Agents can REQUEST work and PROPOSE work. Agents must NOT be able to assert their own authorization or manufacture an approval artifact."**
- Agents are requesting_principal (authenticated from TrustedAuthEvidence)
- Agents cannot create ApprovalArtifact (frozen dataclass, only governance engine can create)
- Agents cannot approve their own requests (prevent_self_approval checks)
- Only humans can grant HUMAN_APPROVAL_REQUIRED approvals

✅ **"Discover the actual runtime path through which Agent A → Agent B occurs. Do not guess the runtime boundary."**
- Runtime boundary discovered: ensure_governed() → run_governed_mutation() → _authorize() → GovernanceEngine.evaluate()
- All mutations funnel through single gate
- Authenticated principal from TrustedAuthEvidence (not agent-supplied)
- Discovery documented in RUNTIME_GOVERNANCE_DISCOVERY.md
