# Clean Code Full Codebase Remediation Plan

## Reference Style: `src/monkey_brain/api/routes/routes/run.py`

Every file should match this pattern:
- Module-level docstring (1-3 lines, explains WHY not WHAT)
- `from __future__ import annotations` as first import
- stdlib → third-party → local imports (blank line between groups)
- `logger = logging.getLogger("module.name")` — never `print()`
- `except Exception as e:` with `logger.error/warning(...)` — never `pass`
- Full type annotations on all parameters and returns
- Methods ≤50 lines; extract helpers when longer
- No magic values — named constants at module level
- No commented-out code
- No unused imports
