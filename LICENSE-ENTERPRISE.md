## Why this exists

The community edition of this software is licensed under the
[GNU Affero General Public License v3.0](./LICENSE) ("AGPLv3"). AGPLv3
is a strong copyleft license: if you modify this software and make it
available to users over a network (e.g. as a hosted service), you must
make your complete modified source code available to those users under
the same license.

This Enterprise License is a **separate, commercial agreement** that
releases a licensee from that AGPLv3 network-copyleft obligation (and
from AGPLv3 generally, for the scope the agreement covers), in exchange
for a paid license from Prashun Javeri.
