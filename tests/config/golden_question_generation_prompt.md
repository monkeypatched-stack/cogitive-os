# Golden Question Generation Prompt for Tablet & Capsule Manufacturing

You are a senior tablet and capsule manufacturing plant operator with deep domain expertise in pharmaceutical production, GMP compliance, and shop floor operations. Your task is to generate a **golden set of questions and expected answers** for a given manufacturing scenario.

---

## Plant Structure (Always True)

The plant is organized as follows:

```
Plant (e.g., Ahmedabad-Tablet and Capsule Manufacturing Plant)
  └── Production Line (e.g., Ahmedabad OSD Line 1)
        └── Stage (e.g., Dispensing, Granulation, Compression, Packaging)
              └── Workstation (e.g., Blending Workstation 1)
                    ├── Worker (operator → reports to → Line Manager → reports to → Plant Manager)
                    ├── Machines (e.g., V-Blender 01, Rotary Tablet Press)
                    ├── Equipment (e.g., High Shear Granulator 01, Weigh Scale)
                    ├── Devices (IoT sensors: temperature, pressure, vibration)
                    ├── SOP (Standard Operating Procedure defining operating parameters)
                    └── Constraints (execution limits, approval gates, quality checkpoints)
```

### Key Relationships
- Each **line** belongs to a **plant** and contains multiple **stages**
- Each **stage** belongs to a **line** and contains multiple **workstations**
- Each **workstation** has one or more **machines** and **equipment** assigned
- Each **workstation** has one or more **workers** (operators)
- Each worker **reports to** a **line manager**
- Each line manager **reports to** the **plant manager**
- Each **workstation** has an **SOP** defining operating parameters
- Deviations from SOP may result in **advantageous or disadvantageous** impacts
- When there is a change or anomaly, a **work order** is generated by the system

---

## Scenario Input Format

Given a scenario, generate questions across these dimensions:

### Scenario Template
```
SCENARIO: [Describe the specific situation]
- What changed or is about to change?
- Which plant/line/stage/workstation/machine is affected?
- What role is the user (operator, line manager, plant manager, QA, maintenance)?
- Are there compliance or SOP implications?
- Is a work order involved?
- Are there downstream or upstream effects?
```

## Question Categories to Generate

For EVERY scenario, generate questions across ALL of these categories:

### 1. Plant Topology (5-8 questions)
Questions about the physical structure and relationships:
- "How many [entities] are in the system?"
- "Which [stages/lines] are linked to [specific line/plant]?"
- "What is the takt time / efficiency of [specific line]?"
- "Where is [specific plant] located?"
- "What is the capacity utilization of [specific facility]?"

### 2. Asset Management (5-8 questions)
Questions about machines, equipment, and their assignments:
- "How many machines / equipment / devices are in the system?"
- "Show details for [specific machine]."
- "Which workstation is [specific machine] assigned to?"
- "Which machines / equipment are assigned to [specific workstation]?"
- "What is the status of [specific machine]?"
- "Which machine parts are low stock?"

### 3. Worker Operations (5-8 questions)
Questions about operators, roles, and reporting:
- "Who operates [specific workstation]?"
- "What stage / line is [specific worker] assigned to?"
- "Who does [specific worker] report to?"
- "Who reports to [specific manager]?"
- "What is [specific worker]'s role?"
- "Who manages workers on [specific line]?"

### 4. SOP Compliance (4-6 questions)
Questions about operating procedures and parameter limits:
- "What is a Standard Operating Procedure?"
- "What SOP is bound to [specific workstation]?"
- "What are the [process] parameters defined in the SOP?"
- "What are the required roles for approval of SOP at [specific workstation]?"
- "What constraints are there for execution at [specific workstation]?"
- "What happens if we operate [machine] above SOP maximum?"

### 5. Work Order Lifecycle (4-6 questions)
Questions about work orders generated from anomalies/changes:
- "How many work orders are open?"
- "Show work orders for [specific machine/workstation]."
- "What is the status of work order [specific ID]?"
- "What events are there for work order [specific ID]?"
- "What is the next maintenance due date for [specific machine]?"

### 6. Batch Record Traceability (8-10 questions)
Questions about BMR, BPR, IPC, yield, and compliance records:
- "What MBMR template is bound to batch [specific batch ID]?"
- "What executed BMR / BPR record was generated for batch [specific batch ID]?"
- "What IPC result is linked to batch [specific batch ID]?"
- "What is the yield reconciliation for batch [specific batch ID]?"
- "What equipment usage ledger is included in the BMR package for batch [specific batch ID]?"
- "What report templates are bound to the batch record package for [specific batch ID]?"
- "What is the batch release status for [specific batch ID]?"
- "Show the full traceability chain for batch [specific batch ID]."
- "What CPP/CQA registry entries are linked to batch [specific batch ID]?"
- "What is missing to generate a BMR for this work order?"
- "Do we have cleaning, equipment usage, IPC, yield, and signatures for [specific batch ID]?"

### 7. Quality & Approval (5-7 questions)
Questions about QA gates, approvals, and audit trails:
- "What approvals are pending for [specific workstation/SOP]?"
- "Are there rejected approvals for [specific SOP]?"
- "Who signed the latest approval for [specific SOP]?"
- "Show audit logs for [specific SOP]."
- "What are the required approval steps for [specific SOP]?"
- "What happens if QA approval is delayed by [N] hours?"
- "What happens if approval is requested but not granted?"

### 8. Production KPIs (6-8 questions)
Questions about operational metrics:
- "What is the OEE of [specific line]?"
- "What is the availability / throughput rate / cycle time?"
- "What is the plan adherence for [specific facility]?"
- "What is the WIP in [specific production]?"
- "What is the scrap rate / yield rate for batch [specific batch ID]?"
- "What is the defect rate DPMO for batch [specific batch ID]?"
- "What is the maintenance compliance rate?"

### 9. What-If Scenarios (10-15 questions)
Hypothetical scenario simulation questions — these are the most critical:
- "What happens if we increase / decrease [parameter] by [N]%?"
- "What happens if we operate [machine] above / below SOP limits?"
- "What happens if [quality metric] variance increases by [N]%?"
- "What happens if QA approval is delayed by [N] hours?"
- "What happens if we skip an in-process quality check?"
- "What happens if SOP v[N] conflicts with SOP v[N+1]?"
- "What happens if [machine] becomes the new bottleneck?"
- "What happens if we add a second [machine]?"
- "What happens if demand spikes by [N]%?"
- "What happens if we shorten planned maintenance windows?"
- "What happens if energy prices increase by [N]%?"
- "What happens if we optimize for [objective] instead of [objective]?"
- "What happens if approval is requested but not granted?"
- "What happens if confidence falls below execution threshold?"
- "What happens if no similar historical cases exist?"
- "What happens if retrieved trajectories disagree?"
- "What happens if execution is attempted without grounding?"

### 10. Maintenance & Preventive (4-6 questions)
Questions about maintenance schedules and equipment health:
- "What is the next maintenance due date for [specific machine]?"
- "What cleaning records are linked to [specific workstation]?"
- "What calibration records are due or pending?"
- "What is the MTBF / MTTR for [specific machine]?"
- "What is the equipment reliability index?"

### 11. Change Control (3-5 questions)
Questions about change management and governance:
- "What change controls are there?"
- "What are the approval steps for a change control?"
- "What is the impact assessment for a proposed process change?"
- "Show open change controls for [specific person] approval."

### 12. Entity Definitions (8-12 questions)
Questions asking "what is an X?" — the system must return definitions, not listings:
- "What is a machine?"
- "What is a workstation?"
- "What is a plant?"
- "What is a production line?"
- "What is a stage?"
- "What is a worker?"
- "What is a Standard Operating Procedure?"
- "What is a work order?"
- "What is a batch record?"
- "What is a change control?"
- "What is a production KPI?"
- "What is a material?"

## Output Format

For each question, provide:

```json
{
  "id": "<category>_<sequence>",
  "category": "<category_name>",
  "question": "<the question>",
  "expect_any": ["<keyword1>", "<keyword2>", "<keyword3>"],
  "role": "<who would ask this: admin|operator|line_manager|plant_manager|maintenance|qa>",
  "expected_answer_summary": "<brief description of what the answer should contain>",
  "golden_answer": "<the exact expected answer if deterministic>"
}
```

---

## Rules

1. **Every question must be answerable from the seeded data in the database.** Do not generate questions about data that doesn't exist.
2. **Use real entity names from the system:** V-Blender 01, Blending Workstation 1, Ahmedabad OSD Line 1, Wet Granulation Workstation 1, AHM-TAB-2026-0001, Aarav Mehta, Prashun Javeri, etc.
3. **Vary the roles.** Not all questions should be asked by admin. Distribute across operator, line_manager, plant_manager, maintenance, and qa.
4. **What-if questions must be routed to the world model simulation (gateway v3).** They start with "What happens if..." and involve process parameter changes.
5. **Definition questions must return definitions, not listings.** "What is a machine?" should return what a machine IS, not a list of all machines.
6. **Include negative cases.** Questions like "What happens if we operate above SOP maximum?" should return "Rejected" or governance enforcement answers.
7. **Include cross-cutting concerns.** Batch traceability, compliance, and approval workflows span multiple entities.
8. **Target 8-12 questions per category** for a total of 80-120 questions per scenario.
9. **Each question should have 2-5 expected keywords** in `expect_any` for automated validation.
10. **Group questions by difficulty:** topology and definitions are easy; what-if and batch traceability are harder.

## Example Scenario

```
SCENARIO: V-Blender 01 at Blending Workstation 1 is showing increased vibration levels.
The vibration sensor detected a 15% increase over baseline. A work order has been
auto-generated. The blending stage SOP requires vibration below threshold before
operation continues. The line manager needs to decide whether to:
  a) Continue operation with monitoring
  b) Stop and inspect
  c) Escalate to maintenance

AFFECTED ENTITIES:
- Machine: V-Blender 01 (MACH-VBL-001)
- Workstation: Blending Workstation 1 (WS-BLEND-001)
- Stage: Wet Granulation
- Line: Ahmedabad OSD Line 1
- Plant: Ahmedabad-Tablet and Capsule Manufacturing Plant
- Worker: Aarav Mehta (operator)
- Line Manager: Prashun Javeri
- Work Order: auto-generated maintenance work order
- SOP: Blending SOP v1.0
- Sensor: Vibration sensor on V-Blender 01
```

For this scenario, generate questions like:
- "What is the current vibration reading of V-Blender 01?" (asset monitoring)
- "What work order was generated for V-Blender 01?" (work order lifecycle)
- "What does the Blending SOP say about vibration limits?" (SOP compliance)
- "Who operates Blending Workstation 1?" (worker operations)
- "What happens if we continue operating V-Blender 15% above vibration threshold?" (what-if)
- "What is the maintenance history of V-Blender 01?" (maintenance)
- "What approval is needed to continue operation?" (quality approval)
- "What is the impact on batch AHM-TAB-2026-0001?" (batch traceability)
